# Pesquisa Acadêmica: Saúde da Pele & Influência Hormonal

Projeto acadêmico para o curso de **Biomedicina (Habilitação em Estética)**.
Tema: *"Influência Hormonal na Saúde da Pele de Adolescentes e Jovens: Uma Abordagem Estética"*.

## Tecnologias Utilizadas
- **Frontend:** HTML5, Tailwind CSS, Chart.js, FontAwesome
- **Backend:** Node.js, Express, Vercel Serverless Functions
- **Banco de Dados:** Supabase (PostgreSQL)
- **Segurança:** Painel Administrativo protegido por autenticação e senhas de acesso

## Estrutura
- `/` - Formulário responsivo com 13 questões em 4 etapas
- `/admin` - Painel analítico com 8 gráficos interativos, KPIs e exportação de CSV
- `/api` - API Serverless integrada ao banco de dados Supabase
